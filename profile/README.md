# CodeLinkOps

AI 驱动的工程组织：**AI 写代码，人负责判断。**

代码全部由 agent 改动与提交，人做需求、设计评审、PR 审查与发布决策。所有改动走 PR，所有功能点挂 GitHub 里程碑，进度与成本自动汇总。

工程规范见 [`.github` 仓库](https://github.com/CodeLinkOps/.github)：

- [工程规范](https://github.com/CodeLinkOps/.github/blob/main/README.md) — 建项目、分支、合入、选型、里程碑
- [Agent 工作约束](https://github.com/CodeLinkOps/.github/blob/main/AGENTS.md) — 各仓库 `AGENTS.md` 的来源
- [模板](https://github.com/CodeLinkOps/.github/tree/main/templates) — `DESIGN.md`、CI

技术栈默认：后端 Rust · Web React · App Flutter
